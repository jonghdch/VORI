## 2. 골든 패스 (11월안)

핵심 루프는 그대로다. 달라진 것은 **판정과 보상이 하루 끝에 한 번** 일어난다는 것.

```
기록하고 → (저녁) 판정하기 · 큰 지출은 이유를 답하고 → 자정 보상 → 펫 키우고 방 꾸며서 → 배웅 → 알
```

| # | 무대 동작 | 터지는 것 (리허설 스크립트로 확인) | 화면에서 누를 곳 · 짚을 곳 (10/8 화면 리허설) |
|---|---|---|---|
| 1 | **큰 지출 등록** — 결혼식 축의금 20만원 | 지출 **RED** · 「기록의 시작」 업적 · AI 질문 생성 | 가계부 작성 → [+ 지출 추가하기] → 내역·금액 입력, 칩 「식비 · 외식」 확인 → [다음 단계](여기서 저장) → [완료하기] → 가계부. 상세 패널 **「AI 판정 · 초과」**, 「판정 보상 — 아직 판정 전」, 판정 카드 **「오늘 미답변 질문 1건」**. 업적은 홈 **「최근 업적」** 의 「기록의 시작」 |
| 2 | **판정하기** | 1차 판정 **PENDING**, 식비 그룹 **빨강** | 판정 카드 [판정 시작하기] → 확인 창 「하루에 한 번 판정할 수 있습니다」 [판정하기] → 머리말 **「1차 판정: 빨강 · 초과. 사유를 답하거나 건너뛰면 최종 판정이 나고, 보상은 오늘 자정에 들어와요.」** |
| 3 | 질문에 **「경조사」 칩**으로 답하기 | 그 지출 **RED → GREEN**, 코인·스탯은 그대로 | 지출 카드(결혼식 축의금 · 200,000) 아래 「Q. …」 질문과 칩 6개 → [경조사] |
| 4 | **완료 → 최종 판정** | **FINALIZED**, 식비 그룹 **빨강 → 초록**, 보상은 자정 예정 | [완료] → 「초록 · 여유 — 소비 판정이 완료됐어요」, 보상 카드 **「자정에 받을 코인 +○○ · 스탯 +○」**, 식비 판정 이유 **「1차 판정은 빨강 · 초과였지만 예외 지출 사유가 인정돼 초록 · 여유로 바꿨어요」** ⭐ — 규칙이 판정하고 AI 는 사유만 본다는 걸 여기서 짚는다 |
| 5 | 업적 화면 | 획득 목록 + 다음 목표 진행률 | 홈 「최근 업적」 또는 업적 화면 |
| 6 | 가구 상점 | **스터디 테마 잠금 해제**(1번 업적의 결과) | 상점 오른쪽 위 **[가구] 아이콘**(기본은 알 탭) → 스터디 가구에 [구매하기] |
| 7 | **책상 · 코르크 보드** 사서 배치 | **스터디 세트 발동 2/2**, 우드는 2/3 미발동(대비) | 마이룸 [보유 가구] 탭 → [배치하기] 두 번. 코르크 보드는 벽, 책상은 오른쪽에 놓이고 펫은 책상 앞이라 가리지 않는다. 방 오른쪽 위 칩 **「배웅 선물 +22.5%」**(개별 7.5% + 스터디 세트 15%) |
| 8 | 펫 배웅 | 세트 보너스가 얹힌 배웅 선물 · 「첫 배웅」 업적 | [펫 상태] 탭 → [배웅하기 (3,120 코인~)] → **브라우저 확인 창 「확인」** → 「보리가 달로 돌아갔어요. 배웅 선물로 3,822 코인을 받았어요.」(버튼 값은 보너스 전) |
| 9 | 알 구매 → 개봉 | 결과 카드 · 새 펫 | 상점 알 탭 기본 알 [구매하기] → [개봉하기] → 새 펫 카드와 **「○○의 이름을 지어 주세요」** — 관객에게 이름을 받아도 좋다 |

**이 각본의 산**
- **1~4번** — 「지출한 이유를 묻는 가계부」가 화면으로 증명되는 자리. 판정을 AI 가 내리는 게 아니라 **규칙(예산 봉투)이 내리고, AI 는 이유를 묻고 사유를 분류만** 한다는 걸 4번의 1차 → 최종 비교로 보여 준다. 다른 팀도 Gemini 를 쓰므로 이 점이 차별점이다.
- **5~7번** — 업적 → 해금 → 구매 → 세트가 하나의 사슬(9월과 같음).

## 3. 시연 계정 세팅

```
python scripts/demo_seed.py              세팅만 (발표용 계정은 이걸로)
python scripts/demo_seed.py --rehearse   세팅 + 위 1~9번을 API 로 실제로 눌러 보는 리허설 (계정을 소모한다)
python scripts/demo_seed.py --checkin --email <이메일>   발표 당일 아침 — 그날 출석만 (출석 창 막기)
```

스크립트가 하는 것(#104):
- 계정·온보딩 → 지출 9건을 **어제와 그 이전 날짜**로 등록(10번째가 무대의 큰 지출 — 업적 조건 10건). 오늘 판정에는 무대 지출만 들어간다.
- 필요한 코인(상품 가격으로 우드 2개 + 스터디 2개)만 **관리자 코인 지급 API** 로 채운다 — 하루 보상이 수백 코인이라 정상 경로로는 시연 가구를 살 수 없다.
- 우드 가구 2개 배치(2/3, 대비용), 펫을 관리자 치트로 **30레벨**까지(배웅 조건).
- 펫 이름(「보리」)을 지어 두고 **그날** 출석까지 해 둔다 — 둘 다 첫 화면에서 팝업으로 뜬다.
  발표용 계정을 전날 만들었으면 발표 날 아침 `python scripts/demo_seed.py --checkin --email <이메일>` 로 그날 출석만 다시 한다.

서버 조건:
- 판정 시각 0(무대 규칙 2). 리허설은 칩으로 답하므로 **Gemini 키가 없어도 된다** — 로컬에서는 일부러 틀린 키로 돌려 한도를 아낀다.
- 관리자 계정(`admin@vori.com`)이 있어야 코인 지급·펫 치트가 된다.
- **배포 서버에서 할 때**: 배포 환경이 정해지면 채운다(5절).

## 4. Gemini 한도 운영 (#102)

- 문장 생성은 모델당 하루 약 20회, 대체 모델까지 약 40회. **11월엔 한국 시각 17시에 풀린다**(태평양 자정).
- 무대에서 Gemini 를 쓰는 것: AI 질문 문구, 글로 쓴 사유 분류, 영수증 인식, 펫 대화, 일일 코멘트. **칩 답변은 안 쓴다.**
- 관리자 → 소비 분석 AI 및 데이터 → **AI 사용량**(`/admin/ai-usage`):
  - 모델별 「오늘 다 씀 · 오후 5시에 풀림」 표시.
  - **질문 문구 AI 생성** 끄기 → 템플릿 질문(「…골라 주거나 가볍게 적어 줄래?」).
  - **일일 코멘트 AI 생성** 끄기 → **발표 전날 밤에 끈다.** 0시 10분 배치가 전날 기록이 있는 사용자마다 1회씩 쓰는데, 그 한도가 발표 날 오후 5시까지 이어진다.
- 한도가 끝나면 펫 대화·영수증은 「오늘 준비한 AI 사용량을 다 썼어요 …」 안내가 나온다(고장이 아니다).
- 경진대회(게스트 다수): 펫 대화 1인당 횟수 `PET_CHAT_DAILY_LIMIT`(기본 10)을 낮춘다 — 4명이면 하루 한도가 끝난다.
