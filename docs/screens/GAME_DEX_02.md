## 세부

[← 도감], 히어로 카드(그림·등급·단계 버튼), 내 기록 카드(이 종족으로 키운 펫 목록: 변종·단계·레벨·부화일·칭호, 배웅일·코인 또는 [마이룸에서 보기 →]).
없는 종족 키면 `/dex` 로 돌린다.
