## 1. 기능 나열

서비스가 하는 일을 분류별로 적었다. 화면이 없는 기능([README 3-3](README.md#3-3-화면-외-개발-대상))에는 "(화면 없음)" 을 붙였다.

### 공개

- VORI 소개 문구·미리보기 카드·기능 카드·FAQ 를 보여 주고 회원가입(로그인 사용자는 홈)으로 보낸다
- 세계관(루미나) 이야기를 3D 달과 챕터 3개로 보여 준다
- 캐릭터 16종(진화 단계·배웅·성격)과 가구 카테고리 10종을 둘러보게 한다
- 이용약관·개인정보처리방침 전문을 보여 준다

### 계정

- 이메일·비밀번호로 가입한다 (필수 약관 2개 동의, 가입 뒤 자동 로그인)
- 가입 보너스 1,000 코인과 시작 펫(강아지)을 준다
- 이메일·비밀번호 또는 구글 계정으로 로그인한다
- 로그인 뒤 계정 상태(설문 전·온보딩 전·완료)에 따라 다음 화면을 고른다
- 소비 프로필 설문 6문항(월 수입 + 단일 선택 5개)을 받는다. 설문 전 계정은 모든 경로가 설문으로 돌아온다
- 설문으로 정한 소비 기준 요약을 보여 주고 온보딩 완료를 저장한다
- 회원 탈퇴를 받는다. 30일 유예 뒤 데이터를 지운다 (화면 없음 — 유예 기간 파기). 그 안에 로그인하면 복구한다

### 기록

- 지출·수입·저축 한 건을 금액·내역·카테고리·결제 수단으로 적는다
- 내역 문자열로 카테고리를 자동 추천하고, 애매하면 칩으로 되묻는다 (화면 없음 — 자동 분류 `POST /categories/categorize`)
- 영수증·결제 캡처 사진으로 금액·내역·날짜·결제수단을 채운다 (화면 없음 — 영수증 인식 `POST /receipts`)
- 저장된 지출을 고치거나 지운다
- 달력(주·월)에서 날짜별 내역·신호·판정 보상을 본다
- 기간 내역을 날짜별 목록으로 보고, 거래수단·카테고리로 거르거나 최근 6개월에서 검색한다
- 지출을 기록하면 100 코인을 준다

### 판정

- 지출마다 신호(여유·적정·초과)를 매기고, 확정 전에는 "(예상)" 으로 보여 준다
- 일반 계정은 20:00 부터 그날 하루 판정을 받는다 (ADMIN 은 언제든, 날짜 선택)
- 초과(RED)·비반복 지출에는 AI 가 사유를 묻고 답을 판정에 반영한다 (화면 없음 — AI 사유 질문)
- 판정 결과로 그룹별 판정 이유·받을 코인·스탯 보상을 보여 준다
- 판정을 안 받았거나 PENDING 인 날을 자정에 1차 판정으로 확정하고 보상을 준다 (화면 없음 — 자정 판정 확정)

### 리포트

- 주·월 단위로 지출·수입·순저축·기록한 날을 보여 준다
- AI 판정 분포와 결제수단별 지출을 보여 준다
- 기간 내역 표에서 고른 날의 상세를 보여 준다
- 말일 12:00 부터 7일 동안 "리포트가 나왔어요" 를 띄우고 읽음 처리한다 (화면 없음 — 월간 리포트 알림)

### 게임

- 코인으로 알(기본·고급·최고급)과 가구를 산다
- 산 알을 개봉해 새 펫을 만나고 이름을 짓는다
- 방에 가구를 배치·회수하고 방 테마를 바꾼다
- 펫 상태(레벨·경험치·스탯)를 보고 상호작용·대화·아이템 사용을 한다
- 펫과 하루 10회 대화한다. 대화 내용은 저장하지 않는다 (화면 없음 — 펫 대화 `POST /pets/active/chat`)
- Lv.30 펫을 배웅하고 배웅 선물 코인을 받는다
- 키운 펫 종족·업적·칭호를 도감에서 보고 업적(최대 3개)·칭호를 장착한다
- 하루 한 번 출석하고 스탯 아이템을 받는다

### 설정

- 프로필(닉네임·이름·나이·직업·월 수입)을 고친다
- 기본 결제수단과 고정비를 정하고 이번 달 스탯별 월 예산을 본다
- 카드·계좌를 등록하고 이름·카드사·잔액을 고치거나 지운다
- 회원 탈퇴를 신청한다 (일반 계정만)

### 관리

- 운영 KPI 6개와 최근 7일 가입 추이를 본다
- 회원 목록을 권한별로 조회한다
- 제재 관리·펫 성장 지원·지출 카테고리 통계·합리성 판정 / AI 룰 설정·AI 대사 로그·AI 사용량·업적 관리 메뉴를 쓴다
- 그 밖 9개 메뉴는 "준비 중" 으로 표시한다
- 시연용으로 자기 펫의 종족·변종·단계·레벨을 바꾸거나 펫을 비운다
- 어드민 계정, 시작 펫, 알 등급·가구·테마·업적·칭호 마스터를 시드로 넣는다 (화면 없음 — 시드 데이터)

### 공통

- 앱 화면에서 주 메뉴·사이드바·하단 탭으로 이동한다
- 계정 메뉴에서 코인·누적 절약·장착 업적을 보고 리포트·도감·환경설정·출석 확인·로그아웃으로 간다
- 알림 종으로 안 읽은 알림 수와 알림 목록을 보여 준다
- 이름 없는 활성 펫이 있으면 이름 짓기를 강제한다
- 서버가 message 를 주지 않으면 상태 코드별 대체 문구를 보여 준다

## 3. 정보구조도

- **Depth1** = 메뉴 항목, **Depth2** = 탭·하위 화면(탭이 없는 화면은 화면 안 구역), **Depth3** = 그 안의 시트·팝업·모드.
- 기능 칸은 화면 문서 문장에서 줄였다. 같은 분류·Depth1 이 이어지면 첫 행에만 적었다.
- 공통 분류의 AppShell 은 가계부 작성(`WAL_ENT_01`)·어드민을 뺀 앱 화면을 감싼다 ([CMN_SHELL_01](CMN_SHELL_01.md)).

## 4. 핵심 경로 점검

클릭 수는 화면을 넘기거나 상태를 바꾸는 버튼만 셌다. 입력칸 타이핑·선택지 고르기는 빼고 괄호로 적었다.

### 4-1. 처음 가입해 첫 기록

흐름도: [README 6-1](README.md#6-1-가입--첫-기록) · [6-2](README.md#6-2-로그인-분기)

| 단계 | 화면 | 버튼 |
|---|---|---|
| 1 | 랜딩 `PUB_LND_01` | [무료로 시작하기] |
| 2 | 회원가입 `AUTH_SGN_01` | (5칸 입력 + 필수 약관 2개) → [회원가입] — 자동 로그인 |
| 3 | 소비 프로필 설문 `ONB_PRF_01` | (6문항 답) → [다음] × 5 → [기준 설정 완료] |
| 4 | 온보딩 `ONB_DONE_01` | 목표별 주 버튼 (예: [첫 지출 기록하기]) |
| 5 | 가계부 작성 `WAL_ENT_01` | (금액·내역 입력, 카테고리 자동 분류) → [저장] → 가계부 날짜 탭 |

- 클릭 수: 10번 (랜딩 1 · 가입 1 · 설문 6 · 온보딩 1 · 저장 1).
- 가입 진입점: 랜딩 히어로·마지막 CTA [무료로 시작하기], 랜딩·스토리 헤더 [회원가입], 로그인 화면 "회원가입" 링크. 구글 계정은 로그인 화면에서 가입·로그인을 겸하고, 이후 로그인 분기(6-2)로 설문에 닿는다.
- 첫 기록 진입점: 온보딩 주 버튼(→ `/wallet/new`). [홈으로 가기] 를 고르면 4-2 경로로 이어진다.

### 4-2. 하루 지출 기록 → 판정 받기

흐름도: [README 6-3](README.md#6-3-하루-소비-흐름-화면--데이터)

| 단계 | 화면 | 버튼 |
|---|---|---|
| 1 | 가계부 날짜 탭 `WAL_MAIN_01` | 주 메뉴 [가계부] → 선택한 날 카드 [지출 추가] |
| 2 | 가계부 작성 `WAL_ENT_01` | (금액·내역 입력) → [저장] (여러 건이면 [저장하고 하나 더]) → 가계부 날짜 탭 |
| 3 | 가계부 날짜 탭 `WAL_MAIN_01` | 20:00 이후 [판정 받기] |
| 4 | 하루 판정 `WAL_JDG_01` | 확인 모달 [판정하기] |
| 5 | 하루 판정 `WAL_JDG_01` | 질문 있음: (사유 칩·자유 입력) → [완료] 또는 [건너뛰고 판정 받기]. 질문 없음: 바로 결과 |
| 6 | 판정 결과 | [가계부로 돌아가기] |

- 클릭 수: 지출 1건 기준 기록 3번(가계부 · 지출 추가 · 저장) + 판정 2~3번(판정 받기 · 판정하기 · 질문 있으면 완료/건너뛰기) = 5~6번.
- 기록 진입점: 가계부 날짜 탭 [지출 추가]·[지출 수정], 홈 [+ 기록] (창 폭 1024px 이하만), 온보딩 주 버튼, 가계부 목록 탭 상세 [이 날 지출 수정].
- 판정 진입점: 홈 오늘 판정 카드([판정 받기]·[이어서 하기]·[결과 보기]), 가계부 날짜 탭 선택한 날 카드의 판정 버튼. 모두 `/wallet/analysis` 로 간다.
