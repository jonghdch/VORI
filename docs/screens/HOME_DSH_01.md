## 상태별 화면

| 상태 | 보이는 것 | 사용자가 할 수 있는 것 |
|---|---|---|
| 로딩 | ② 스켈레톤, ④ "불러오는 중…" | ② 버튼, 다른 메뉴 이동 |
| 실패 | API 마다 따로 실패해도 화면은 뜬다. 오류 문구는 없다 | 새로고침 |
| 빈 | 펫 없음: ① 안내 + [상점 가기] · 지출 없음: ④ 빈 문구 | [상점 가기], [지출 추가하기] |
| 권한 없음 | 비로그인이면 `/login` (`ProtectedRoute`) | — |

## 접근성

- 키보드: 이동하는 요소는 모두 `button` 이다. ② 띠와 제목 옆 링크에 포커스 테두리가 있다.
- ② 띠는 `aria-labelledby` 로 제목과 묶고, 로딩 중 숫자 자리에 `aria-busy` 와 숨김 글자 "불러오는 중"을 둔다.
- ⑥ 판정 점은 색으로만 구분된다.

## 참고

- API: `GET /users/me/home`, `GET /pets/active`, `GET /monthly-reports/unread`, `GET /achievements`, `GET /ledger?yearMonth=`, `GET /spending-plan?yearMonth=`, `GET /daily-judgments/today`.
- 반응형: 폭 1024px 이하는 카드를 한 줄씩 쌓는다. 폭 480px 이하는 ② 버튼도 세로로 쌓는다.
- ⑥ 점 표시는 홈 캘린더(`.home-cal`)에만 적용한다. 소비 리포트 캘린더는 그대로다.

## 의문·미해결

- ⑥ 판정 점이 색으로만 구분돼 스크린 리더와 색각 이상 사용자에게 판정이 전달되지 않는다.
- 이전에 있던 사용률 막대와 "오늘 쓸 수 있는 돈 (예상)" 문구는 이번 디자인에서 빠졌다.
