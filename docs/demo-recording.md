## 1. 녹화 전 준비

- [ ] **최신 main 받기** — `git pull`
- [ ] **판정 시각 설정 두 곳 확인** — 둘 중 하나라도 빠지면 낮에 질문 화면이 안 뜬다
  - 루트 `.env` → `vori.ai-judge.open-hour=0`
  - `frontend/.env.local` → `REACT_APP_AI_ACTIVE_FROM_HOUR=0`
- [ ] 백엔드·프론트 켜기
- [ ] **새 시연 계정 만들기** — `python scripts/demo_seed.py`
  - 끝에 **`OK 10 / FAIL 0`** 이 나와야 한다
  - 마지막 줄의 이메일을 메모한다(비밀번호는 `Vori!2026`)
- [ ] 그 계정으로 로그인
- [ ] **어드민은 시크릿 창에서** `admin@vori.com` / `1234` 로 로그인하고 `/admin/rationality-rules` 를 열어 둔다

> ⚠️ **어드민을 같은 브라우저의 다른 탭에서 로그인하면 안 된다.** 로그인이 세션 쿠키 하나로 돌아가서
> 시연 계정이 로그아웃되고, 그 뒤 화면은 어드민 계정으로 보인다.

- [ ] **영수증 사진은 오늘 날짜 영수증으로** — 날짜가 다르면 다른 날짜 행이 생겨 가계부가 꼬인다.
  전화번호·카드번호처럼 남의 정보가 찍혀 있으면 가리거나 다른 영수증을 쓴다

## 4. 녹화 — 순서대로

**여기서 녹화를 시작한다.** 화면의 값이 아래 표와 다르면 멈추고 원인부터 본다.

| # | 조작 | 확인할 값 | 캡처 |
|---|---|---|---|
| 1 | 가계부 → + 지출 추가 → + 지출 추가하기 → **"결혼식 축의금" · 200000** | 카테고리 칩 **식비 · 외식** | |
| | [다음 단계] → [완료하기] → 홈 | 최근 업적 **'기록의 시작' 완료** | |

| | AI 소비 판정 카드 → [판정 시작하기] | 질문이 뜬다 | 📸 질문 화면 |
| 2 | 답변 *"친구 결혼식 축의금이라 안 낼 수가 없었어요"* → [완료] | 같은 행이 **'합리적'** | |
| 3 | 칭호 화면 | '절약 고수' **73%** 진행률 | 📸 진행률 |

**녹화를 끝낸다.**

> ⚠️ **5번에서 카드 이름을 보고 누른다.** 코르크 보드 대신 액자를 사면 우드가 3/3 으로 발동해
> "우드는 아직 발동하지 않았다" 는 대사가 깨지고 분양가도 9,213 이 아니라 9,916 이 된다(9/23 실제로 겪었다).
>
> 분양 버튼에 **"분양하기 (7,400 코인~)"** 이 떠도 정상이다. 보너스를 뺀 값을 보여줄 뿐이고, 누르면 9,213 이 나온다.
